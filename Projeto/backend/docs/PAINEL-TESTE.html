Como usar este painel

  1. Cole a URL do Render (ex.: https://fluxo-api-w858.onrender.com) — pode colar sem o /api/v1.
  2. Clique em Testar conexão. Se aparecer verde, a API respondeu.
  3. Clique em Rodar diagnóstico: não cria dados, serve para validar cada deploy.
  4. Quer testar o fluxo real? Rodar fluxo completo cria 1 conta de teste e executa cadastro → login → saldo → transferência recusada → RBAC → logout.
  5. Na aba Testar rotas, faça login com a conta criada e dispare qualquer endpoint (Pix, cartões, agendamentos, recuperação de senha...).
  6. Para testar a recuperação de senha: (1) solicite a recuperação informando CPF, e-mail ou telefone, (2) emita o código de 6 dígitos como ADMIN no backoffice ou via php artisan senha:gerar-codigo {identificador}, (3) valide o código de 6 dígitos e (4) cadastre a nova senha.
  7. Se algo der errado, clique em Exportar relatório e me envie o arquivo.

Se a conexão falhar

  • !
    Erro de rede / "Failed to fetch"
    a) o serviço está dormindo (plano Free) → espere 30-60s e tente de novo; b) URL errada; c) falta config/cors.php no deploy (o pacote novo já traz).
  • !
    Responde 503 no /health
    banco inacessível ou migration pendente — veja o JSON do health e os Logs do Render.
  • !
    "rota inexistente → 308"
    seu deploy está com o pacote ANTIGO. Faça o deploy da branch atualizada para corrigir.
  • !
    429 Too Many Requests
    limite de 60 req/min (login e recuperação: 10/min). Espere 1 minuto.
