# 4.4 — Quadro de Gestão das Atividades

## Objetivo

O quadro de gestão das atividades do projeto Fluxo é utilizado para
acompanhar o andamento das tarefas da equipe durante os Checkpoints do
projeto.

O acompanhamento considera o status atual das atividades e a
responsabilidade principal de cada integrante.

## Colunas de acompanhamento

| Status | Significado |
|---|---|
| Backlog | Atividade identificada, mas ainda não priorizada |
| A Fazer | Atividade planejada e ainda não iniciada |
| Em Andamento | Atividade em execução |
| Em Revisão | Atividade concluída tecnicamente e aguardando validação |
| Concluído | Atividade finalizada e validada |

## Processo de acompanhamento

O quadro é atualizado conforme a evolução das atividades do projeto.

A movimentação padrão é:

**Backlog → A Fazer → Em Andamento → Em Revisão → Concluído**

O ProjectLibre é utilizado em conjunto com este quadro para controle de
datas, duração, dependências, recursos e marcos do projeto.

O GitHub é utilizado como evidência da evolução dos artefatos e do código.

## Relação com os Checkpoints

### Checkpoint 1
Escopo, requisitos iniciais, regras de negócio e casos de uso.

### Regularização pós-CP1
Correções solicitadas após a apresentação do primeiro checkpoint.

### Checkpoint 2
Requisitos finais, prototipação, documentação de casos de uso, DER,
diagrama de classes e atualização do planejamento.

### Checkpoint 3
Backend REST, testes, TDD, regras transacionais, segurança, auditoria e
implantação.

### Checkpoint 4
Frontend Web, aplicativo Mobile, integração, testes finais, manual e
entrega final.
