Fluxo · Painel de testes

Teste a API do Laravel e confirme se ela consegue consultar o PostgreSQL.

1. Conectar à API

Desconectado

Cole a URL base do serviço, sem precisar adicionar /api/v1. O teste chama /api/v1/health; o HTML não acessa o PostgreSQL diretamente.

2. Criar usuário

Use dados de teste. O cadastro pode criar registros permanentes no banco conectado.

3. Login

O token fica somente na sessão atual do navegador e é apagado ao sair ou fechar a sessão.

Não autenticado.

4. Transferência entre contas

Entre com o usuário que será a conta de origem. Para descobrir o ID da conta de destino, entre com o outro usuário e clique em “Saldo / conta”; copie conta.id da resposta e depois volte a entrar com o usuário de origem.

A API espera valor_centavos (inteiro). O painel converte R$ 1,00 em 100 centavos. O teste de idempotência envia duas vezes o mesmo corpo com a mesma chave e compara o ID da transação e o saldo. Use contas de teste.

5. Simular depósito na conta

Envie um depósito de teste para a conta do usuário autenticado. Atenção: esta função exige que o Laravel disponibilize uma rota de depósito; o painel não altera o saldo diretamente no PostgreSQL.

O painel envia {valor_centavos, descricao} e uma chave Idempotency-Key. A rota sugerida é apenas um exemplo: ajuste para a rota real do seu backend. Se retornar 404 ou 405, a rota não está disponível.
